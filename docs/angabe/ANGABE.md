# Semesterprojekt SWEN3 | BIF5

Dokumentenmanagement-System: Archivierung im FileStore, OCR über eine Queue, KI-Zusammenfassung, Tagging und Volltextsuche (Elasticsearch).

Die vollständige Angabe liegt unter [semester-project.pdf](semester-project.pdf).

## Use Cases

1. Dokument hochladen (OCR, Indexierung, Zusammenfassung)
2. Dokument suchen (Volltext / Fuzzy in Elasticsearch)
3. Dokumente verwalten (Update, Delete, Metadaten)
4. Zusätzlicher Use Case (noch festzulegen, mit eigenen Entitäten)

## Technologie

C# / .NET 10 / ASP.NET Core, Docker, RabbitMQ, PostgreSQL, Elasticsearch, GenAI.
